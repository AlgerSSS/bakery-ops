数据流向 —— 从写入方到消费方

实线是写入（数据进库的唯一通道），虚线是现算（视图与前端聚合，不占存储）。全库只有五个写入方，其中 res_api 每晚 KL 23:00 与 14:20 各跑一次，其余由人触发。

图上五个写入方之外，没有任何进库通道 —— 这是「最小数据存最多信息」的前提：同一个事实只有一个写入者。
唯一的例外是 daily_revenue：res_api 写 POS 实测口径、财务站写月结模板口径，两个口径共存于一张表由 import_source 区分，重叠部分由 v_revenue_reconciliation 呈现为一行差异而非冲突。
