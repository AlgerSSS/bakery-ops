# HOT CRUSH HBTI Web Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build, deploy and verify a trilingual HOT CRUSH HBTI site that securely issues one real RES `Pistachio Green Jewel` coupon per member and campaign.

**Architecture:** A standalone Next.js TypeScript application in `hbti-web/` renders the mobile experience. Server-only routes validate encrypted personal links, coordinate idempotency in a dedicated MongoDB Atlas collection, and call RES through a narrow connector whose credentials remain in Vercel environment variables.

**Tech Stack:** Next.js App Router, React, TypeScript, CSS Modules/global CSS, Zod, MongoDB Atlas, Vitest, Testing Library, Playwright, Vercel.

- `hbti-web/tests/` — unit, component and integration tests.
